# Enco X3 for Mac v0.2.1

首个公开安装包：原生 macOS 菜单栏应用，适配已配对并连接的 OPPO Enco X3（PID 067410）。

## 下载

- `EncoX3-Mac-0.2.1-arm64.dmg`：推荐。打开后把 App 拖入 Applications。
- `EncoX3-Mac-0.2.1-arm64.zip`：解压版，包含相同 App。
- `INSTALL.zh-CN.md`：首次启动、蓝牙权限、使用与卸载说明。
- `SHA256SUMS.txt`：安装包校验和。

**架构为 Apple Silicon / arm64，不包含 Intel 版本。** 最低部署目标 macOS 13，实机验证为 macOS 27.2；其他系统与固件尚未验证。

**采用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证。** 首次下载启动可能需要按 [Apple 官方说明](https://support.apple.com/102445) 在“隐私与安全性”中选择“仍要打开”，然后允许蓝牙访问。

## 功能

- 左右耳及充电盒电量；未上报显示未知。
- 关闭、通透、自适应通透，以及智能/深度/中度/轻度降噪。
- 六个 EQ 预设和关闭/固定/跟随三种耳机空间模式。
- 双设备连接信息只读显示。
- 卡片式菜单栏面板、系统深浅外观、状态同步和断线重试。
- 修正充电盒插画与名称重叠，电量三列统一对齐。

## 验证与限制

- 255 项离线协议与恢复逻辑检查通过；DMG 校验、挂载后 App 签名验证、ZIP 完整性检查通过。
- 控制模式已在本机逐项验证并恢复原值；本次打包没有再次改变耳机设置。
- 启动时控制通道可能超时一次，随后自动重试。
- 本机充电盒电量需要一只耳机入盒并保持开盖才能上报。
- 没有 Apple 查找网络、iCloud 配对、Apple 自动切换或系统 AirPods 弹窗；耳机空间模式不等同 Apple 动态头部追踪。
- 自定义 EQ 支持切到现有预设，不提供曲线编辑；双设备不提供切换控制。
