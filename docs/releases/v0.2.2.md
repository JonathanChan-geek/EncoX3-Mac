# Enco X3 for Mac v0.2.2

修复首次连接时界面长时间等待的问题，并加入正式应用图标。

- GUI 蓝牙连接、查询、设置及回读改为异步处理；启动先显示面板和连接进度。
- 使用缓存的厂商 SDP 服务，连接失败后才重新发现，消除重复安排重试。
- 新增蓝底双耳塞应用图标和菜单栏模板图标。
- 菜单展开期间继续定期刷新状态。
- 开发产物移入隐藏目录，安装脚本默认只保留一个主应用安装位置。

本机最终版实测：面板显示调用完成 **0.452 秒**，控制通道打开 **2.834 秒**，完整状态 **3.384 秒**。此为已配对连接、权限可用状态下的本机结果，不保证其他系统或固件的耗时。

270 项离线检查通过；异步降噪、EQ、空间控制各完成一次往返实测，成功 ACK 并精确回读，最终恢复“降噪关闭 / EQ 自定义 / 空间关闭”。

## 安装

退出旧版，打开 `EncoX3-Mac-0.2.2-arm64.dmg`，将 App 拖入 Applications 并替换。另提供相同 App 的 ZIP、安装说明和 SHA-256 校验文件。

Apple Silicon / arm64，最低部署目标 macOS 13，实机验证 macOS 27.2。采用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证，首次下载启动参见随包安装说明。

本应用提供耳机自身控制，不提供 iCloud 配对、Apple 查找网络、Apple 自动切换或系统 AirPods 界面。充电盒未上报时显示未知；双设备只读显示。

GPL-3.0-or-later，对应源码为 `v0.2.2` 标签。详细证据见 `docs/evidence/2026-09-23-v022-acceptance.md`。
